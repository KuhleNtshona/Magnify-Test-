# Magnify Church website

This is a simple static website. It works with just three files and can be edited in Visual Studio Code.

## Open it in VS Code

1. Open Visual Studio Code.
2. Choose **File → Open Folder**.
3. Select this folder: `C:\Users\KuhleN\Documents\Codex\2026-08-17\is`
4. Open `index.html` to change the page content, `styles.css` to change the design, or `script.js` to change the menu behaviour.

## Preview it

Install the **Live Server** extension in VS Code, then right-click `index.html` and choose **Open with Live Server**.
